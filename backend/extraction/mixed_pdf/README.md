# Mixed PDF Dispatcher

**Owner:** Manoj  
**Part of:** AI-Accelerator document intelligence pipeline.

Routes each page of a mixed PDF (some digital, some scanned) to the appropriate pipeline:
- **Digital pages** → `digital_pdf` extractor (PyMuPDF, no OCR)
- **Scanned pages** → `scanned_pdf` extractor (PaddleOCR + YOLO)

Outputs a single combined list of `NormalizedBlock` objects for the entire PDF, with corrected source references (original filename and page number). Page-level metadata is generated separately by `backend/extraction/page_profile.py`.

---

## What this module does

- Uses `detect_pdf_type()` from `backend/extraction/detector.py` to classify each page as `digital` or `scanned` (based on presence of native text).
- Creates a temporary single-page PDF for each page and calls the corresponding extractor.
- Rewrites `source_ref` to point to the original PDF (filename and page).
- Deletes the per-page JSON files created by the underlying extractors, keeping only the final combined JSON.
- Aggregates all blocks into one list and saves the final JSON via `save_blocks()`.

> **Important:** This module does **not** produce `page_metrics` blocks – those are handled by `page_profile.py`. The deletion of per-page JSON files is a convenience to avoid clutter in the `output/blocks/` directory.

## Usage

### Standalone (without the pipeline)

```python
from backend.extraction.mixed_pdf.mixed import extract_mixed

blocks = extract_mixed("path/to/mixed.pdf", document_id="my_doc")
for block in blocks:
    print(f"{block.type}: {block.text[:50] if block.text else 'table'}")
```

### As a Tool (inside the LangGraph pipeline)

```python
from backend.extraction.mixed_pdf.tool import MixedPDFTool

tool = MixedPDFTool()
state = {
    "file_path": "path/to/mixed.pdf",
    "document_id": "my_doc"
}
new_state = tool.run(state, {})
blocks = new_state["blocks"]          # combined NormalizedBlock[]
profiles = new_state["page_profiles"] # list of PageProfile (metadata)
```

---

## How it works (step by step)

1. **Classify pages** – `detect_pdf_type()` returns `per_page_types` (e.g., `["digital", "scanned", "digital", ...]`).
2. **Create temporary PDFs** – for each page, a single-page PDF is written to a temporary directory.
3. **Call appropriate extractor** – if `digital`, calls `extract_digital()`; if `scanned`, calls `extract_scanned()`.
4. **Fix source references** – all extracted blocks are updated to refer to the original PDF file and correct page number.
5. **Delete per-page JSONs** – the extractors each save a JSON file (e.g., `page_1_blocks.json`); these are removed to avoid clutter.
6. **Combine and save** – all blocks are merged and saved as a single JSON (e.g., `Mixed_blocks.json`).

---

## Configuration

No configuration is required inside this module. Thresholds for page classification (text length >5 chars = digital) are defined in `detector.py`. Visual region detection parameters (e.g., `min_visual_area`) are passed to `extract_scanned()` via its own config.

---

## Output

- **`state["blocks"]`** – a list of `NormalizedBlock` objects (text, tables, image placeholders, etc.) from all pages.
- **`state["page_profiles"]`** – a list of `PageProfile` objects, one per page, generated by `page_profile.py`.
