# Scanned PDF Extractor

**Owner:** Manoj  
**Part of:** AI-Accelerator document intelligence pipeline.

Extracts text and visual regions from **scanned PDFs** (image-only pages) using OCR and computer vision.  
Combines **PaddleOCR** (text recognition) with **YOLOv8 + contour detection** (diagrams, photos, figures).  
Outputs `NormalizedBlock` objects that conform to the shared schema (`backend/core/schemas.py`).

---

## What this module does

- **OCR** – uses PaddleOCR (PP-OCRv4) to extract text and character-level bounding boxes.
- **Visual region detection** – applies YOLOv8 (if available) and OpenCV contour detection to locate meaningful non-text areas (images, charts, diagrams). Falls back to contour-only if YOLO fails.
- **Paragraph grouping** – merges OCR lines into paragraphs by empty lines.
- **Placeholders** – creates `image_caption` blocks for each detected visual region with bounding boxes (in PDF coordinates).
- **Page-level metadata** – **not** included in blocks; handled separately by `backend/extraction/page_profile.py`.

> **Important:** Page-level metadata (text length, image regions, etc.) is **not** produced here. It is generated by the shared `page_profile.py` module, in line with the reviewer's requirement: *"Remove the page_metrics blocks from digital.py, that data stays in page_profiles"* (applies to scanned as well).

## Usage

### Standalone (without the pipeline)

```python
from backend.extraction.scanned_pdf.scanned import extract_scanned

blocks = extract_scanned("path/to/scanned.pdf", document_id="my_doc", min_visual_area=50000)
for block in blocks:
    print(f"{block.type}: {block.text[:50] if block.text else 'image'}")
```

### As a Tool (inside the LangGraph pipeline)

```python
from backend.extraction.scanned_pdf.tool import ScannedPDFTool

tool = ScannedPDFTool()
state = {
    "file_path": "path/to/scanned.pdf",
    "document_id": "my_doc"
}
config = {"min_visual_area": 50000}  # optional, defaults to 50000
new_state = tool.run(state, config)
blocks = new_state["blocks"]          # list of NormalizedBlock
profiles = new_state["page_profiles"] # list of PageProfile (metadata)
```

## Configuration

| Parameter | Default | Description |
|-----------|---------|-------------|
| `min_visual_area` | 50000 px² | Minimum area (pixels² at 200 DPI) for a region to be considered a visual element. |
| `use_gemma` | `False` | If `True`, sends detected visual regions to Gemma for description (placeholder). |

These can be passed via the `config` dictionary to the tool or directly as arguments to `extract_scanned()`.

---

## How it works (step by step)

1. **Render page** – each PDF page is rendered as a PIL image at 200 DPI.
2. **OCR** – PaddleOCR extracts text lines and their bounding boxes.
3. **Visual region detection** – combines YOLO (if available) and contour detection (text masked out) to find large non-text areas.
4. **Filtering** – regions below `min_visual_area` are discarded; long horizontal strips (headers/footers) are skipped; on very text-heavy pages, huge regions are ignored to avoid false positives.
5. **Paragraph grouping** – OCR text is split into paragraphs by empty lines.
6. **Block creation** – text paragraphs become `text`/`heading` blocks; visual regions become `image_caption` blocks with their bounding boxes.
7. **JSON output** – saves the block list to a JSON file (same name as PDF, `_blocks.json`). This JSON is later consumed by the mixed dispatcher or directly by the pipeline.

---

## Output

- **`state["blocks"]`** – a list of `NormalizedBlock` objects:
  - `type="text"` or `"heading"` – OCR-derived paragraphs.
  - `type="image_caption"` – placeholders for visual regions, with `metadata.pending_vision = True`.
- **`state["page_profiles"]`** – generated by `page_profile.py` (shared).

## Dependencies

- `PaddleOCR` + `paddlepaddle` – OCR engine.
- `ultralytics` (YOLO) – optional, for object detection; falls back gracefully.
- `opencv-python` – contour detection and image preprocessing.
- `Pillow` – image handling.
- `numpy` – array operations.
- `PyMuPDF` – PDF page rendering.
