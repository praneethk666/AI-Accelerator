# Multimodal Vision Enrichment Module

The **Vision Module** (`backend/vision/`) enriches visual figures, engineering schematics, charts, and technical diagrams by generating detailed textual descriptions using state-of-the-art vision-language models (VLMs).

---

## 1. Key Capabilities & Features

- **Automated Figure Captioning** ([`vision_enrichment_tool.py`](file:///d:/AI-Acc-updated/AI-Accelerator/backend/vision/vision_enrichment_tool.py)):
  - Discovers `pending_vision` image blocks generated by extractors, crops high-resolution image regions, and queries configured VLM providers.
  - Replaces raw `image` blocks with search-ready `image_caption` blocks containing verbatim component labels, part numbers, and dimensions.
- **Domain-Specific Visual Prompting**:
  - Automatically tailors visual prompts for automotive service manuals (exploded views, fasteners, torque specs), mechanical CAD drawings, or electronic schematics.
- **Image Hashing & Description Caching**:
  - Computes perceptual image hashes to skip re-captioning identical visual elements across documents.
- **Multimodal Provider Fallback**:
  - Seamlessly falls back across NVIDIA NIM (Llama 3.2 Vision), Google Gemini, and OpenAI GPT-4o Vision.

---

## 2. Dependencies & Testing

- **Pillow (`PIL`) & fitz (PyMuPDF)**: Image cropping and format conversion.
- **backend.core.vision_client**: Multimodal VLM client.
- **Configuration Blueprint (`config/global.yaml`)**:
  ```yaml
  vision:
    provider: openai                  # NVIDIA NIM / OpenAI / Google
    model: meta/llama-3.2-11b-vision-instruct
    dpi: 150
    min_image_px: 150
    timeout_s: 120
  ```
- **Verification**:
  ```powershell
  pytest tests/test_image_tool.py
  ```
